# Recall Decision 预设计

> 独立延后需求备忘，未实现，不是本次评分方案的前置；不保留字段、算法或报告 schema 草案。

## 何时才需要重新讨论

只有消费者明确要求“原断言存在失败，但总分达标也判最终通过”时，才讨论额外的验收政策。仅需要不同效果不同分数、比较两个 FAIL 的表现、或调整某项贡献，均不需要 Decision。

这些评分需求已由 [现行断言计分](../recall-judge-dsl.md) 覆盖：多个 judge rubric 独立裁定，AI 与显式 opt-in 的机械判据各自使用可选 score，框架统一求和；当前最终通过仍要求所有声明断言通过。

## 保留边界

- 不恢复维度表、第二套赋分或总分，不把标准分、scope 或机械插件任意输入当作贡献配置。
- 不将原始失败改写为通过，不以其他正分吞掉评测错误，也不能放行已确认的失败提前停止。
- 不因分支、分类或评级的存在而默认引入本能力，当前没有 Decision 作者 DSL。

重新立项须先确认第二个独立消费者也需要分数放行，再决定是否由框架承载，另写设计、验收与实施计划；本备忘不提前选择 threshold/required 等字段。
